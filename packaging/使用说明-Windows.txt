素材中心 1.4.0 · Windows 64 位便携版

适用于 Windows 10/11 x64。完整解压 ZIP 后，双击“素材中心.exe”。
请保留同目录内的 resources、DLL 等文件，不要只复制 exe，也不要直接在压缩包里运行。
已包含 Electron 与 Python，不需要另外安装 Python、Node 或 WebView2。

点击“连接素材文件夹”选择整理好的目录。文件保持原位，支持文件夹浏览、搜索、标签、收藏、预览和音频试听。
素材缩略图支持通过系统原文件拖放接口拖出，Windows 下的实际资源管理器及剪辑软件兼容性尚未实机验证。

索引、标签与界面缓存保存在：%APPDATA%\素材屿
退出应用后可备份该目录。更新时替换整个解压目录；不要删除资料库目录。
Mac 与 Windows 的素材路径不同，不能直接使用另一系统的索引，应重新连接文件夹。

此包已进行结构、官方运行环境校验及共用后端测试，尚未在 Windows 实机验收。首次运行可能出现未签名程序提示。
部分专业编码无法内嵌预览，可用系统应用打开原文件。

本版新增：NAS 共享标签、可预览和滑动视频的回收站、素材时长/大小/尺寸展示、DNG/RAW 与 MTS 等兼容预览、设置/外观/图标选择和可调标签区。
共享标签须两端均更新并连接同一级 NAS 根目录后启用。NAS 管理记录和回收站保存在隐藏的 .material-center 目录，请一并备份。
回收站操作会移动实际文件；永久删除需确认，还原不覆盖同名文件。预览缓存保存在本机，不覆盖原素材。
安装包已包含媒体解码组件，无需另行下载。Mac 版本仅支持 Apple M 系列芯片，不支持 Intel。

1.1.1：去除目录树左侧竖线；TTF/OTF/TTC/WOFF/WOFF2 字体无需安装即可预览样张；新增 PDF、SVG、PDF/PostScript 兼容 AI、EPS 首页预览。仅包含 Illustrator 私有数据的 AI、缺失外部资源或未嵌入字体的文件仍可能无法准确显示。Mac 安装包仅支持 M 系列。
