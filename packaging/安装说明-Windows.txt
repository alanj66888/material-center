素材中心 1.4.0 · Windows 64 位安装版

1. 完整解压本压缩包。
2. 退出旧版素材屿或素材中心。
3. 双击“素材中心-1.4.0-Windows-x64-安装程序.exe”，按向导安装。
4. 从桌面或开始菜单打开“素材中心”。

安装程序不需要联网，不要求另外安装 Python、Node 或 WebView2。
默认仅为当前用户安装到 %LOCALAPPDATA%\Programs\MaterialCenter，可选择安装目录及是否创建桌面快捷方式。
可在 Windows“设置 → 应用”或开始菜单中卸载。

为兼容旧版，资料库继续使用 %APPDATA%\素材屿，里面的索引、收藏、标签保留。
卸载仅移除本版程序及快捷方式，不删除该资料库，也不删除原始素材。
旧便携版文件夹由用户自行保留或删除，请勿删除其中保存的个人文件。

程序及安装器未做发行者签名，首次运行可能出现系统提示。
此包已进行编译、内容及资源检查，尚未在 Windows 实机完成安装、启动与卸载验收。

本版新增：NAS 共享标签、可预览和滑动视频的回收站、素材时长/大小/尺寸展示、DNG/RAW 与 MTS 等兼容预览、设置/外观/图标选择和可调标签区。
共享标签须两端均更新并连接同一级 NAS 根目录后启用。NAS 管理记录和回收站保存在隐藏的 .material-center 目录，请一并备份。
回收站操作会移动实际文件；永久删除需确认，还原不覆盖同名文件。预览缓存保存在本机，不覆盖原素材。
安装包已包含媒体解码组件，无需另行下载。Mac 版本仅支持 Apple M 系列芯片，不支持 Intel。

1.1.1：去除目录树左侧竖线；TTF/OTF/TTC/WOFF/WOFF2 字体无需安装即可预览样张；新增 PDF、SVG、PDF/PostScript 兼容 AI、EPS 首页预览。仅包含 Illustrator 私有数据的 AI、缺失外部资源或未嵌入字体的文件仍可能无法准确显示。Mac 安装包仅支持 M 系列。

1.2.0 优化大素材库：分页读取、按可见区域绘制、本机预览缓存、后台扫描与有界解码队列。首次升级会自动更新本机索引，收藏与标签保留。

1.3.0：修正加载破图、目录文字裁切，增强 Windows 目录字体与浅色菜单；增加素材区空白处拖动框选、Shift 连选及 Ctrl/⌘ 追加选择。单次最多选择 5000 个素材。程序、安装器和快捷方式改用蓝紫图标，安装时刷新图标通知。
